# AnvilID admin console

The admin console is a static single-page app (React, TypeScript, Vite, TanStack Router/Query/Table,
shadcn/ui on Tailwind v4). `anvilid` serves it at `/console/`. It talks only to the management API
(`/api/admin/v1`).

## Sign-in

The console is the built-in public OAuth client `anvil-console` of the `system` tenant. It uses the
authorization code flow with PKCE (oidc-client-ts), with issuer `{origin}/t/system`, redirect URI
`{origin}/console/callback` and scope `openid admin:read admin:write`. Tokens are kept in
`sessionStorage`. Admins are users of the `system` tenant. The console currently manages the
`default` tenant.

## Development

Node 22.12 or newer is required.

```sh
npm ci
npm run dev        # http://localhost:5173/console/ ; /api and /t are proxied to localhost:8080
```

| Script | Purpose |
| --- | --- |
| `npm run build` | Type-check, build into `dist/`, then write `.br` and `.gz` sidecars (`scripts/compress.mjs`) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run gen:api` | Regenerate `src/api/schema.d.ts` from `../docs/openapi/admin-v1.json` |
| `npm run check:api` | Fail if the committed `src/api/schema.d.ts` is out of date |

After changing the management API, run `just openapi-update` at the repository root, then
`npm run gen:api` here, and commit both files.

`src/routeTree.gen.ts` is generated by the TanStack Router plugin from `src/routes/` during `dev` and
`build`. It is committed so that a fresh checkout type-checks. CI fails if a build changes it.

From the repository root, `just console-build` and `just console-check` run the same steps.

## Content Security Policy

The console is served with `script-src 'self'`. Do not add inline scripts, and do not add libraries
that inject inline `<style>` elements without first recording the need for a CSP exception.
