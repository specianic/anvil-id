# Security policy

The security policy is maintained in one place,
[`SECURITY.md`](https://github.com/specianic/anvil-id/blob/main/SECURITY.md) at the root of the
repository. It lists:

- the supported versions that receive security fixes;
- how to report a vulnerability privately;
- what happens after a report, the response targets and the coordinated disclosure process
  (GitHub Security Advisories with a CVE, fixes in the open-source release);
- what is in and out of scope.

**Please do not report security problems in public issues, discussions or pull requests.** Follow
the reporting instructions in `SECURITY.md`.

Related pages:

- [Threat model](THREAT-MODEL.md): assets, attackers, trust boundaries and the controls for each.
- [Security review scope](SECURITY-REVIEW-SCOPE.md): what the external security review covers.
- [Compatibility policy](COMPATIBILITY.md) and [Upgrading](UPGRADING.md): how security fixes are
  released and what an upgrade needs.
