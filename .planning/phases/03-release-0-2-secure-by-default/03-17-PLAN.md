<objective>
Consent: decide after authentication, a consent page with remembered grants, deny/allow delivered through the response mode, and
a connected-apps page where users revoke consent (revoking that client's token families).

Purpose: OIDC-13 (consent screen, skippable for first-party clients, remembered and revocable); audit events.
Design note: consent is a small separate state machine (flow/consent.rs + service/consent.rs, FlowKind::Consent) rather than a
variant of the login FlowState, so it never touches the login engine; it reuses FlowService's binding helpers. Record this in the
summary for ARCHITECTURE §9.
Output: core consent flow/service, authorize integration, UI pages, tests.
</objective>
