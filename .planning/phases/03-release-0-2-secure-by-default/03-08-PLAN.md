  <behavior>
    - peer 203.0.113.9 (untrusted) + `X-Forwarded-For: 1.2.3.4` → 203.0.113.9

    - multiple XFF header lines are joined in order; all entries trusted → leftmost entry
    - `Forwarded: for="[2001:db8::1]:4711";proto=https, for=198.51.100.7` with header mode `forwarded` parses quoted IPv6+port and IPv4; keys case-insensitive
    - entry "unknown"/"_obf"/garbage stops the walk → last trusted hop
    - `::ffff:10.0.0.2` peer matches 10.0.0.0/8
    - header mode x-forwarded-for ignores `Forwarded` and vice versa (no mixed-source spoofing)
    - issuer in discovery and cookie attributes are unchanged by `X-Forwarded-Proto: http` / `X-Forwarded-Host: evil.test`
    - proptest: for random honest trusted chains with an arbitrary spoofed prefix, the result is never taken from the spoofed prefix
