  <behavior>

    - active age < period − prepublish → no actions; age ≥ period − prepublish, no next → [Generate{alg, next}]
    - next age ≥ prepublish and active age ≥ period → [Promote{retire: active (expires_at = now + 1 h + 5 min), activate: next}]
    - next age < prepublish → no promotion even if active is overdue (a key never signs before it has been published for prepublish)
    - retired with expires_at ≤ now → [Delete]; retired not yet expired → kept
    - alg removed from the enabled set: its active key is not rotated further, never deleted while active (RS256 always enabled)
    - policy invariant: RotationPolicy::new rejects prepublish < JWKS_MAX_AGE
  </behavior>
