contract/mod.rs per 01-RESEARCH.md Patterns 7 and 8 (macro form):
- `pub struct TestStorage { pub storage: Arc<dyn anvil_core::ports::Storage>, pub _guard: Box<dyn Any + Send + Sync> }`.
- Helpers: `now_ms()` = `truncate_to_ms(OffsetDateTime::now_utc())`; `new_tenant()` with unique slug
  (`format!("t-{}", Uuid::now_v7().simple())`); `new_code(expires_in: Duration)` with a unique CodeHash built from
  two `Uuid::now_v7()` byte arrays, all fields populated including `nonce: Some(..)` and `token_family_id: Some(..)`
  so round-trips exercise nullable columns; `seed_tenant_and_code(s)`.
- Contract fns (each `pub async fn name(s: &TestStorage)`, panicking with clear messages):
  - `tenant_create_and_get`: create returns the tenant; get(id) and get_by_slug(slug) return equal values (ms precision); unknown id/slug → None.
  - `tenant_slug_conflict`: second create with same slug, new id → `Err(StorageError::Conflict(_))` (negative test).
  - `consume_code_once`: create_code then consume → `Consumed(code)` equal to the inserted fields + tenant_id; second consume → `AlreadyConsumed { family_id }` equal to the code's token_family_id.
  - `consume_code_expired`: expires_at = now - 1s → `NotFound`; and a code whose expires_at == now → `NotFound` (strict `>`).
  - `consume_code_unknown`: random hash → `NotFound`.
  - `consume_code_wrong_tenant`: tenant B consuming tenant A's code → `NotFound`; afterwards tenant A can still consume it (`Consumed`) — tenant isolation negative test.
  - `create_code_duplicate_conflict`: inserting the same code_hash twice → `Err(Conflict)`.
  - `consume_code_concurrent_single_winner`: Pattern 8 — N = 32, 10 rounds, `tokio::sync::Barrier` + `JoinSet`,
    every result must be `Ok`; assert `(won, lost) == (1, 31)`; `NotFound` panics.
- `#[macro_export] macro_rules! storage_contract_tests { ($factory:path) => {...} }` expanding one
  `#[tokio::test(flavor = "multi_thread", worker_threads = 4)]` per contract fn (all eight, listed in one place),
  each calling `$factory().await` then `$crate::contract::<name>(&s).await`. Backends cannot skip a test.
Never put test-only behavior in non-`contract` code (CLAUDE.md).
