<decisions_applied>
Crate-layout decision (orchestrator, from Phase 2 research). It overrides 01-RESEARCH.md Pattern 3:
1. Storage port traits (Storage, TenantRepo, GrantRepo), their domain types, ConsumeOutcome and StorageError
   live in `anvil-core` (`anvil_core::ports` + `anvil_core::model`), NOT in `anvil-storage`. This avoids a
   dependency cycle once anvil-core's protocol logic needs the ports. async-trait, serde, uuid, time and
   thiserror are pure and allowed in core.
2. `anvil-storage` keeps the shared contract test suite (feature `contract`) and backend-agnostic helpers.
   It depends on anvil-core.
3. Backends (`anvil-storage-sqlite`, `anvil-storage-postgres`) normal-depend on anvil-core only (plus sqlx),
   and depend on anvil-storage only as a dev-dependency (for the contract suite).
4. Dependency rules apply to NORMAL dependencies only. anvil-web may dev-depend on concrete storage crates
   (for QUAL-02 tests on both backends) but must never normal-depend on them.
</decisions_applied>
</context>

`ports.rs` (`#[async_trait::async_trait]`, dyn-compatible):
```rust
pub trait Storage: Send + Sync + 'static {
    fn tenants(&self) -> &dyn TenantRepo;
    fn grants(&self) -> &dyn GrantRepo;
}
pub trait TenantRepo: Send + Sync {
    /// Err(StorageError::Conflict) on duplicate slug (unique index; never check-then-insert).
    async fn create(&self, tenant: &NewTenant) -> Result<Tenant, StorageError>;
    async fn get(&self, id: TenantId) -> Result<Option<Tenant>, StorageError>;
    /// Tenant resolution: the only lookup that does not take a TenantId.
    async fn get_by_slug(&self, slug: &str) -> Result<Option<Tenant>, StorageError>;
}
pub trait GrantRepo: Send + Sync {
    /// Err(Conflict) on duplicate code_hash.
    async fn create_code(&self, tenant: TenantId, code: &NewAuthorizationCode) -> Result<(), StorageError>;
    /// Atomic: single UPDATE ... WHERE consumed_at IS NULL AND expires_at > now RETURNING ...
    async fn consume_code(&self, tenant: TenantId, code_hash: &CodeHash, now: OffsetDateTime)
        -> Result<ConsumeOutcome, StorageError>;
}
pub enum ConsumeOutcome {
    Consumed(AuthorizationCode),
    AlreadyConsumed { family_id: Option<TokenFamilyId> },
    /// Unknown, expired, or belongs to another tenant. Callers map all of these to invalid_grant.
    NotFound,
}
#[derive(Debug, thiserror::Error)]
pub enum StorageError {
    #[error("conflict: {0}")] Conflict(String),
    #[error("corrupt stored data: {0}")] Corrupt(String),
    #[error("storage backend error: {0}")] Backend(#[source] Box<dyn std::error::Error + Send + Sync>),
}
```
