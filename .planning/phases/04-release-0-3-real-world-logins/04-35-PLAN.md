<objective>
Gap closure (orchestrator decision 5): make the tenant settings `email_otp` (6-digit code) and `magic_link` (link) mean
different things.
- The `login_code` email renders the code and/or the link depending on which settings are enabled (optional template
  variables).
- Routes and core enforce each toggle separately.
- The anvil-mail template contract check and its tests follow.

Purpose: today either toggle enables both. 0.3 docs and the console present them as two settings, so they must behave as two.
Output: optional-variable contract, guarded default template, per-toggle enforcement and pages, negative tests.
</objective>
