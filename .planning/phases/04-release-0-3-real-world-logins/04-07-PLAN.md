Query|FormPost, token_auth: Basic|Post, email_trusted: bool, api_profile, apple_audience: Option<String> }` (`apple_audience` is
`Some` only for the Apple preset: the `endpoints.issuer` override when set — mocks/tests — else `APPLE_ISSUER`; it is both the
expected ID-token `iss` and the client-secret `aud`). Cases: Google preset -> discovery issuer accounts.google.com,
scopes `openid email profile`, PKCE on; Microsoft `common` -> MicrosoftTemplate; Apple -> fixed endpoints, FormPost when scope has
name/email, PKCE off, token_auth Post; GitHub -> OAuth2, scopes `read:user user:email`, PKCE on, api base `https://api.github.com`
unless overridden; every endpoint override wins; Oidc requires metadata and errors if `metadata.issuer != config.issuer`; empty

iat=now, exp=now+300). Callers pass `resolved.apple_audience` (Apple's real `APPLE_ISSUER` for production presets; the mock issuer
when the connection overrides `endpoints.issuer`). Tests: production preset -> aud `https://appleid.apple.com`; issuer override ->
aud equals the override; claims never contain anything but iss/sub/aud/iat/exp.
`pub fn authorization_url(&ResolvedProvider, client_id, redirect_uri, state, nonce: Option<&str>, code_challenge: Option<&str>,
login_hint: Option<&str>) -> Url` (query encoding; response_mode=form_post only for Apple).

claims.rs — `validate_id_token(token, &Jwks, &ResolvedProvider, client_id, expected_nonce: Option<&str>, now) -> Result<Map, UpstreamTokenError>`:
order alg/signature -> iss rule -> aud contains client_id (multiple aud => azp == client_id) -> `exp > now - 60s`, `iat <= now + 60s`
-> nonce equality when expected. Errors are a typed enum (`Signature, Issuer, Audience, Expired, IssuedInFuture, Nonce, MissingClaim`).
Rejected: alg none, HS256 signed with the RSA public key bytes, unknown kid, Google iss `https://evil`, Microsoft tid missing / not a
UUID / outside allowed tenants, aud mismatch, expired, future iat, nonce mismatch or missing when expected.
`UpstreamIdentity { subject, email: Option<String>, email_verified: bool /* already AND-ed with trust */, given_name, family_name,
name, metadata: Map /* ms tid/oid, google hd */ }`; `normalise_oidc(&claims, &ResolvedProvider, trust: bool)`;
`normalise_apple(&claims, user_json: Option<&str>, trust)` (tolerant bool parser for Apple only; user JSON parsed, trimmed, max 200
chars per name part, control chars stripped; ignored if malformed); `normalise_github(user: &Value, emails: &Value, trust)` (subject =
id number as string, never login; email = the primary&&verified entry or None); `normalise_oauth2(&Value, &ClaimMapping, trust)`
(subject required; email_verified only if mapped AND trust). Google `hd` allow-list enforced when configured.

linking.rs — `link_decision(&LinkInputs { identity: &UpstreamIdentity, existing_link: Option<&IdentityLink>, link_user_active: bool,
email_match: Option<EmailMatch { user_id, email_verified }>, auto_link_enabled: bool, connection_kind: ConnectionKind,
registration_allowed: bool }) -> LinkDecision { SignIn(UserId), AutoLink(UserId), PendingLink { candidate: Option<UserId> },
JitCreate { email_verified: bool }, Refuse(RefuseReason { Inactive, NoAccount }) }`. Table: existing link + active -> SignIn
(email ignored); existing link + inactive -> Refuse(Inactive); no link + verified&trusted upstream email + local verified match +
auto_link + kind != Microsoft -> AutoLink; no link + any local email match otherwise -> PendingLink (candidate shown only when the

the decision is never AutoLink; for Microsoft never AutoLink; with an existing active link always SignIn(link.user_id).
