  <behavior>
logout.rs — `EndSessionRequest { id_token_hint: HintCheck, client_id: Option<String>, post_logout_redirect_uri: Option<String>,
state: Option<String>, ui_locales: Option<String> }`; `validate_end_session(&req, hint_client: Option<&Client>, client_by_id:
Option<&Client>, current_session: Option<CurrentSession { user_id, session_id }>) -> EndSessionDecision { LogoutNow { redirect:
Option<PostLogoutRedirect { uri, state }> }, Confirm { client_id: Option<String>, redirect: Option<PostLogoutRedirect> },
Error(LogoutError { InvalidIdTokenHint, RedirectUriNotRegistered, IdTokenHintRequired, ClientMismatch }) }`. Cases:
valid hint (aud contains a known client; client_id matches aud if given) and session matches hint sub (and sid if present) or no
session -> LogoutNow (redirect iff URI given and exactly registered for that client, state echoed only if sent); hint Invalid ->
Error(InvalidIdTokenHint); hint client unknown -> InvalidIdTokenHint; client_id given but not in hint aud -> ClientMismatch; URI not
in the client's list (string equality, `?foo=bar` appended fails) -> RedirectUriNotRegistered; URI with neither hint nor client_id ->
IdTokenHintRequired; client_id + registered URI, no hint -> Confirm with redirect; no params / only state / hint for another session ->
Confirm without redirect (signed-out page). Never returns a redirect to an unregistered URI (proptest over random URIs).
`build_post_logout_redirect(uri, state) -> String` appends only `state` (preserving the registered URI's own query).
`logout_token_claims(issuer, client_id, sub, sid, jti, now) -> Map` (exact claim set; unit test asserts keys == expected set and no
`nonce`). `classify_delivery(outcome: DeliveryOutcome { Status(u16), Network, Timeout, Blocked }, attempts, created_at, now) ->
DeliveryResult` (200/204 Delivered; 400 GiveUp; other 4xx GiveUp; 5xx/Network/Timeout Retry with `next = now + min(10s * 2^attempts,
1h)`, GiveUp once `now >= created_at + 24h`; Blocked GiveUp).

resource.rs — `parse_resources(values: &[String]) -> Result<Vec<String>, CoreError>` (each absolute URI per url crate, no fragment,
no query, http(s) or other absolute scheme, ≤ 2048 chars, deduplicated preserving order) -> InvalidTarget otherwise;
`validate_resources(&requested, &client.allowed_resources)` exact string match else InvalidTarget; `downscope(granted, requested)`
(empty requested -> granted; requested must be ⊆ granted else InvalidTarget); `audience(resources, client_id) -> Audience { One(String),
Many(Vec<String>) }` with serde serialising One as string; `userinfo_audience_ok(aud: &[String], client_id, issuer) -> bool`
(contains client_id or `{issuer}/userinfo`).

policy/mfa.rs — `effective_policy(tenant: MfaPolicy, client: Option<MfaPolicy>) -> MfaPolicy` = max by strictness (Required > Optional
> Off; org slot documented for Phase 6); `AcrRequest { None, Voluntary, Essential }` and `acr_request(acr_values: &[String],
claims_acr_essential: Option<&[String]>) -> AcrRequest` (MFA asked iff ACR_MFA requested; essential via claims request);
`mfa_requirement(policy, acr: AcrRequest, session_is_mfa: bool, user_has_factor: bool) -> MfaRequirement { None, SecondFactor, Enroll,
Unmet }` per table: session already MFA -> None; Off+no request -> None (0.2 TOTP users not prompted); Optional+factor -> SecondFactor;
Optional+no factor -> None; Required+factor -> SecondFactor; Required+no factor -> Enroll; request (voluntary/essential)+factor ->
SecondFactor; voluntary+no factor (not Required) -> None; essential+no factor (not Required) -> Unmet. Exhaustive test over the full
cartesian product with an explicit expected table; `acr_for(amr)` helper returning ACR_MFA iff amr contains "mfa".
