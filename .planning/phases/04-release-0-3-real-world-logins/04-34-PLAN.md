   `require_verified_email` to upstream accounts (decision 1). This plan only passes `None` from the existing caller.

Purpose: the storage contract is the single place these invariants hold; doing all SQL in one plan keeps `.sqlx` and both
migrations consistent. Output: two migrations, port + model changes, both backends, 7 new contract tests, wiring, web tests.
