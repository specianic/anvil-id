  `:root{--anvil-primary:#…;…}` plus a dark `@media (prefers-color-scheme: dark){:root{…}}` block only when colors_dark is set, else
  `:root{color-scheme: light}` when any light color is customised; then custom CSS verbatim. Deterministic ordering; snapshot test.
- `sniff_logo(bytes) -> Result<&'static str /* content type */, LogoError>`: PNG/JPEG/WebP signatures; SVG (`<svg`, `<?xml`), GIF,
