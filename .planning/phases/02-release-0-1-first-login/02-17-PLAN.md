Targets:
- `jwt_decode`: `anvil_jose::jws::decode_header` and `verify_jwt` with a fixed generated JWKS (built once with `std::sync::OnceLock`) and arbitrary token bytes (lossy UTF-8).
- `client_assertion`: `verify_client_assertion` with fixed rules and JWKS.
- `authorize_parse`: `parse_raw(data)` then `validate(&raw, Some(&fixed_client))` with a fixed confidential and a fixed public client.
- `redirect_match`: an arbitrary (registered list, requested, app type) passed to `redirect_matches`, asserting the web-client invariant `redirect_matches(.., Web) == registered.contains(requested)`.
Also fuzz `parse_basic` inside `client_assertion` (split the input).
`scripts/fuzz.sh`: `smoke` runs each target with `-runs=10000`, and `run <target> <seconds>` runs `-max_total_time=<seconds>`. Use `cargo +nightly fuzz run --fuzz-dir fuzz` from the repo root. A crash makes the script exit non-zero and print the artifact path. `fuzz/.gitignore` ignores corpus/artifacts/target.
