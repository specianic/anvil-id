**Config keys (ARCHITECTURE §13; env = ANVILID_ + upper-case):** public_url (default http://localhost:8080), listen (127.0.0.1:8080),
data_dir (./anvilid-data), database_url (default `sqlite://{data_dir}/anvilid.db`), kek (base64 secret, env ANVILID_KEK), kek_file
(default `{data_dir}/kek`), smtp_url (secret), smtp_from (default `AnvilID <no-reply@{public host}>`), theme_dir, tls_cert, tls_key,
breach_check (`hibp` default | `off`), breach_check_url (default https://api.pwnedpasswords.com), no_migrate, insecure_http, log_format (`json`|`pretty`,
default pretty in dev mode, json otherwise), config (path to anvilid.toml, default ./anvilid.toml if present).
clap holds `Option<T>` only (no clap defaults or env), so figment can apply precedence: `Serialized::defaults(Config::default())` → `Toml::file`
→ `Env::prefixed("ANVILID_")` → `Serialized::globals(cli_overrides)`. Use `figment.find_metadata(key)` to show the source in `config show`.

**Rules:**
- Never log database URLs, the KEK, the SMTP URL, setup tokens (except the one deliberate `Setup URL:` info line on install), or `admin setup-url` output beyond stdout.
- KEK resolution: env `kek` → kek_file if it exists → otherwise generate into kek_file (0600, warn "back up {path}: losing it makes signing keys unrecoverable"), but **refuse** to generate when the database is Postgres (several nodes would each generate a different KEK).
- serve.lock: SQLite only, `std::fs::File::try_lock()` on `{data_dir}/serve.lock`. A second `serve` on the same data dir exits with a clear error. `admin setup-url` and `migrate` do not take the lock (Pitfall P10).
- Dev mode = `public_url.is_dev_mode()`. `insecure_http` allows http on a non-loopback host and uses the dev cookie policy (add `insecure_http: bool` to `anvil_web::AppConfig`, with dev_mode() = is_dev_mode || insecure_http). It is logged as a warning on every start.
- Argon2 pool permits = `available_parallelism()`, with OWASP default params.
