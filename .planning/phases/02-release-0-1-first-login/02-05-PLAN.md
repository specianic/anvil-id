<task type="auto">
  <name>Task 2: User, self-service, session, flow and grant repositories, including atomic contracts</name>
  <files>crates/anvil-storage-sqlite/src/{users.rs,sessions.rs,flows.rs,grants.rs,lib.rs}</files>
  <action>
UserRepo: `create` inserts user + optional credential + optional token + optional email in one writer tx (Conflict → rollback; the contract checks nothing is left behind). `complete_verification` and `complete_recovery` consume with `UPDATE self_service_token SET consumed_at=? WHERE token_hash=? AND tenant_id=? AND kind IN (…) AND consumed_at IS NULL AND expires_at>? RETURNING …` inside the tx, then apply the effects. Recovery revokes sessions and families: `UPDATE browser_session SET revoked_at` and `UPDATE token_family SET revoked_at, revoked_reason='user_recovery' WHERE user_id=? AND revoked_at IS NULL`. `delete` removes the user's rows and revokes families.
SessionRepo and FlowRepo enforce expiry in every read.
GrantRepo:
- `create_code` inserts the family then the code in one tx.
- `consume_code` keeps the Phase 1 single UPDATE … RETURNING plus the loser-classification read.
- `rotate_refresh` runs in one writer tx: `UPDATE refresh_token SET consumed_at=? WHERE token_hash=? AND tenant_id=? AND consumed_at IS NULL AND expires_at>? AND family_id IN (SELECT id FROM token_family WHERE revoked_at IS NULL AND absolute_expires_at>?) RETURNING family_id`. If that hits a row → insert the child and return the family. If not, and the token exists with consumed_at set → revoke the family (`refresh_reuse`, keep any existing reason) → ReuseDetected. Otherwise NotFound.
- `record_jti`: `INSERT … ON CONFLICT(tenant_id, kind, value_hash) DO UPDATE SET expires_at=excluded.expires_at WHERE replay_guard.expires_at <= ?`. Rows affected 1 → Recorded, 0 → Replayed.
- `revoke_family` is idempotent (`WHERE revoked_at IS NULL`).
`Storage::purge_expired` batch-deletes expired rows per table (LIMIT via rowid subquery) and returns the total.
Delete `pending.rs`, drop its module, and wire every accessor in `impl Storage`.
