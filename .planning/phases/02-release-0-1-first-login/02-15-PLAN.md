and applies the Fetch-Metadata layer), lib.rs, state.rs or the harness. AppState helper methods you add live in your files with

**Routes (relative to the tenant base):** `GET/POST /ui/login[?request=]`, `GET/POST /ui/registration[?request=]`,
`GET/POST /ui/verification[?token=]`, `GET/POST /ui/recovery[?token=]`. `/setup` is installation-level (handler ignores the tenant;
uses the system tenant for its flow row). POST URLs carry `?flow={id}`. Flow cookie set on GET (SameSite=Strict), cleared on completion.
Status codes: a form re-render with errors → 400; message pages → 200; success → 303. Pages that carry tokens are already covered by
`Referrer-Policy: no-referrer` (shell layer). When registration is disabled, the login page has no "create account" link.
After a successful login without `request`, render `message.html` with the signed-in message (no account page in 0.1).
setup_done renders mgmt client id/secret, `token_endpoint = {public_url}/t/system/token`, `admin_api_base = {public_url}/api/admin/v1`,
with `Cache-Control: no-store`.
