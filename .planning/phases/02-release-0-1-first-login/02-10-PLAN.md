ClientService holds that fn pointer, and the wiring (02-16/02-18) passes `oauth::redirect::validate_redirect_uri`. Unit tests pass a
simple test validator. The same applies to sealing: `seal_new_key` lives here and uses `anvil_jose::keys::generate_rs256`, `Kek::seal`
and the model constants `SIGNING_KEY_PURPOSE`/`signing_key_aad`.

**Decisions:** user creation by an admin either sets a password (policy applies; hashing via the PasswordHasher port) or
`invite: true` (issues an Invitation self-service token + `invitation` email, link `{issuer}/ui/recovery?token=…`, 7 d).
The setup URL is `{public_url}/setup?token={plaintext}`. The management client is created in the system tenant with
client_id `mgmt-<random>`, auth `client_secret_basic`, grant `client_credentials`, scopes `["admin:read", "admin:write"]`,
and require_pkce true (irrelevant for this grant). Tenant slugs match `^[a-z0-9][a-z0-9-]{1,62}$`, and `system`/`default` are reserved for bootstrap.
Pagination limit is clamped to 1..=200, default 50.
