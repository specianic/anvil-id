**API shape** (JSON, snake_case, utoipa ToSchema on DTOs):
- `GET/POST /api/admin/v1/tenants`, `GET/PATCH/DELETE /api/admin/v1/tenants/{slug}` (scope admin:tenants:*)
- `GET/POST /api/admin/v1/tenants/{slug}/clients`, `GET/PATCH/DELETE …/clients/{client_id}`, `POST …/clients/{client_id}/secret` (rotate) (admin:clients:*)
- `GET/POST /api/admin/v1/tenants/{slug}/users`, `GET/PATCH/DELETE …/users/{user_id}` (admin:users:*)
- list: `?after=<uuid>&limit=<1..200>` → `{items, next_cursor}`; create → 201 + Location; delete → 204; unknown → 404 problem
- validation → 422 problem with `errors: [{field, message}]`; conflict → 409
- client create body per ClientInput (02-10); response includes `client_secret` only on create/rotate
- user create body `{email, password?, invite?, email_verified?, username?, claims?}` (never returns password data)
The admin API is installation-level. If `ResolvedTenant.base` is not Root (e.g. `/t/acme/api/admin/v1`), return 404. Never apply the browser CSRF layer (bearer-authenticated, no cookies). No CORS in 0.1.
