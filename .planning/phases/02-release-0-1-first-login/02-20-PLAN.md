**Facts:** the bare binary defaults to 127.0.0.1:8080, which is unreachable through `-p` (Pitfall P9), so the image sets
`ENV ANVILID_LISTEN=0.0.0.0:8080`. public_url stays the default `http://localhost:8080` (dev mode). Pick the distroless image tag
(`gcr.io/distroless/static-debian12:nonroot` or debian13; verify which exists) and pin it by digest. Base the image on the static binary from
`scripts/build-musl.sh x86_64-unknown-linux-musl`, copied in (no Rust toolchain in the image). The writable WORKDIR is `/data` owned by
nonroot (create it via a COPY --chown of an empty dir, because distroless has no shell).
