**Parallel-execution rules (wave 2):** own only `crates/anvil-mail/**` (src + tests). Worker tests need an `OutboxRepo`. Do NOT depend on the
storage backends, which are rewritten in parallel. The worker therefore depends on a narrow
`OutboxAccess` trait instead of the whole `Storage`. Production wraps `Arc<dyn Storage>` in `StorageOutbox`, and tests implement `OutboxAccess` with an
in-memory `OutboxRepo` in `tests/support/mod.rs` (test code only, CLAUDE.md).
The real-backend path is proven end to end by Playwright + Mailpit (02-20).

**Design (RESEARCH Pattern 8):** no SMTP configured → the binary does not start the worker (02-18). Rows stay pending and expire.
Backoff: attempt n → now + min(30 s · 2^(n-1), 1 h). Mark rows failed permanently (`next_attempt_at` = expires_at) after 8 attempts.
Claim lease: 2 min.
</context>
