<task type="auto">
  <name>Task 1: Sample relying party (examples/node-rp)</name>
  <files>examples/node-rp/{package.json,package-lock.json,server.js,README.md}, .gitignore</files>
  <action>
ES module, Node ≥ 20, deps `openid-client@6.9.1` and `express@5.3.0` (check the latest patch on npm). Generate package-lock with `npm install`.
Env: `ISSUER`, `CLIENT_ID`, `CLIENT_SECRET`, `PORT` (default 3000), `BASE_URL` (default `http://localhost:$PORT`), `SESSION_SECRET` (random at start when unset).
State lives in an in-memory session map keyed by a random cookie. Use no session library, and set the cookie HttpOnly with SameSite=Lax.
Routes:
- `/` shows a login link, or the signed-in user.
- `/login` builds verifier, challenge, state and nonce, then redirects via `client.buildAuthorizationUrl` with scope `openid profile email`, `code_challenge_method=S256`.
- `/callback` calls `client.authorizationCodeGrant(config, currentUrl, {pkceCodeVerifier, expectedState, expectedNonce})`, then `fetchUserInfo`, stores the tokens and redirects to `/me`.
- `/me` renders `<dd id="sub">`, `<dd id="email">` and `<dd id="refresh-count">`.
- `/refresh` calls `client.refreshTokenGrant`. Store the new refresh token (it is rotated) and increment refresh-count, then call UserInfo again with the new access token and render `/me`.
- `/healthz` returns `ok`.
Call `client.allowInsecureRequests(config)` only when the issuer host is `localhost` or `127.0.0.1` (dev mode), with a comment explaining why. Never log tokens.
README: how to run it against `anvilid serve`.
Add `node_modules/`, `/anvilid-data/`, `/e2e-results/`, `tests/e2e/test-results/` and `tests/e2e/playwright-report/` to .gitignore.
  </action>
