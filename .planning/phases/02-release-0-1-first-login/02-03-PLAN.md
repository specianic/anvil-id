  <name>Task 1: Page templates and CSS</name>
  <files>themes/default/templates/*.html, themes/default/static/anvil.css</files>
  <action>
- `base.html`: semantic HTML5 with `lang="en"`. Link the stylesheet `{{ page.asset_base }}/anvil.css`, no other links. Add a dev-mode banner when `page.dev_mode` ("Development mode: not for production use"), a `<main>` block, and accessible labels. Include no favicon link (it would cause an external request in some browsers).
- `form.html`: a macro `render(form)` that outputs `<form id="{{ form.id }}" method="post" action="{{ form.action }}">` and a hidden `csrf_token` input. For each field it outputs a `<label for=name>`, then `<input id=name name=name type=kind value=value(omitted for password) required autocomplete>` and the field messages with `role="alert"` for errors. It then outputs the form-level messages and `<button type="submit" id="{{ form.id }}-submit">`. Hidden fields render without a label.
- `login.html`, `registration.html`, `verification.html` (a single "Confirm email" button that POSTs the token in a hidden field: link scanners must never consume tokens), `recovery.html` (email request), `recovery_reset.html` (new password; the token is in a hidden field), `setup.html` (first admin: email + password), `setup_done.html` (shows `<code id="mgmt-client-id">` and `<code id="mgmt-client-secret">` with a one-time warning, plus the token endpoint and admin API base), `message.html` (generic "check your email" / "you are signed in"), `error.html`.
- In `error.html`, map `error_key` to a fixed sentence. Keep these sentences stable, because snapshot tests and the conformance config depend on them: `redirect_uri_mismatch` → "The redirect URI in this request is not registered for this client.", `unknown_client` → "This application is not registered.", `invalid_request` → "The sign-in request is invalid.", `flow_expired` → "This sign-in attempt expired. Please start again.", `csrf` → "This form submission could not be verified. Please try again.", `not_found` → "Page not found.", `server_error` → "Something went wrong."
- Links between pages (forgot password, create account) use `page.links.*` and are omitted when null.
- CSS: extend anvil.css with a readable centred card layout, focus styles and error colours (AA contrast). No @import, no web fonts, no url() to external hosts.
