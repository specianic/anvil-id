**Rules (RESEARCH Patterns 2, 4, 5, 7):**
- Session token: `random_token()`, stored as `secret_hash`. Session lifetime 14 d absolute, 12 h idle (constants, documented). Rotate on login: revoke the old session and create a new one.
- Flow cookie token and CSRF token: independent random tokens. The Flow row stores both hashes, and every POST must present both.
- Messages use stable keys: `login.invalid_credentials`, `registration.disabled`, `registration.email_taken`, `password.too_short`, `password.too_long`, `password.breached`, `recovery.sent`, `recovery.invalid_token`, `verification.invalid_token`, `verification.done`, `flow.expired`, `service.overloaded`.
- Never echo passwords in FormDescription values. Non-secret values (email) are echoed on validation errors.
- Emails are enqueued as NewEmail with template `verification`/`recovery`/`invitation`/`password_changed` and payload keys `tenant_name`, `email`, `link`, `expires_in`. Expiry: verification 24 h, recovery 1 h, invitation 7 d. Links: `{issuer}/ui/verification?token=…`, `{issuer}/ui/recovery?token=…`.
- The registration email-enumeration hardening is not in scope. Use the plain `registration.email_taken` conflict path (RESEARCH Pattern 7).

pub enum FlowState { Login(LoginState), Registration(RegistrationState), Verification(VerificationState),
  Recovery(RecoveryState), Setup(SetupState) }                    // serde tagged
pub enum FlowInput { Login { identifier: String, password: String }, Register { email: String, password: String, name: Option<String> },
  ConfirmVerification { token: String }, RequestRecovery { email: String }, ResetPassword { token: String, password: String },
  Setup { email: String, password: String } }   // manual Debug redacting passwords and tokens
pub enum Effect { VerifyPassword{..}, CreateSession{ user_id }, CreateUser{..}, EnqueueEmail{..}, CompleteVerification{..},
  CompleteRecovery{..}, Render(FormDescription) }
pub fn transition(state: FlowState, input: FlowInput) -> (FlowState, Vec<Effect>);   // pure; validation via policy/normalize_email

// service/session.rs
pub struct SessionService { pub storage: Arc<dyn Storage>, pub clock: Arc<dyn Clock> }
pub struct NewSessionCookie { pub token: secrecy::SecretString, pub session: BrowserSession }
impl SessionService {
  pub async fn create(&self, tenant: TenantId, user: UserId, acr: &str, amr: &[String], replaces: Option<SessionId>) -> Result<NewSessionCookie, CoreError>;
  pub async fn current(&self, tenant: TenantId, cookie_token: Option<&str>) -> Result<Option<BrowserSession>, CoreError>; // touches idle expiry
  pub async fn revoke(&self, tenant: TenantId, id: SessionId) -> Result<(), CoreError>; }

// service/flow.rs

pub struct StartedFlow { pub flow_id: FlowId, pub cookie_token: SecretString, pub form: FormDescription }
pub enum FlowOutcome { Render(FormDescription) /* 400 on errors, 200 otherwise */, SignedIn { cookie: NewSessionCookie, continue_to: Option<AuthRequestId> },
  Message { key: &'static str }, SetupSubmitted { email: String, password: SecretString } }
pub struct FlowService { pub storage: Arc<dyn Storage>, pub clock: Arc<dyn Clock>, pub hasher: Arc<dyn PasswordHasher>,
  pub breach: Arc<dyn BreachChecker>, pub policy: PasswordPolicy }

  pub async fn submit(&self, cx: &FlowContext<'_>, flow_id: FlowId, cookie_token: Option<&str>, csrf_token: &str,
    input: FlowInput, current_session: Option<SessionId>) -> Result<FlowOutcome, CoreError>;  // Forbidden on CSRF/cookie mismatch; flow.expired → Render with flow.expired message on a restarted flow
