## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | cargo test (+ insta snapshots); console `npm run typecheck` + `check:api`; Playwright (chromium + nojs) with axe |
| **Config file** | Cargo workspace; tests/e2e/playwright.config.ts; admin-ui/package.json |
| **Quick run command** | `cargo test -p <crate> --test <file>` / `cd admin-ui && npm run typecheck` |
| **Full suite command** | `just ci` + `tests/e2e/run.sh sqlite` (and `postgres` at the gate) |
| **Estimated runtime** | quick ~60 s; full ~40 min |

## Sampling Rate

- **After every task commit:** targeted cargo test + clippy for the crate; console tasks typecheck
- **After every plan wave:** `cargo test --workspace --locked`, `npm run check:api && npm run typecheck`, `scripts/check-security-tests.sh`, `tests/e2e/run.sh sqlite <wave specs>`
- **Before `/gsd:verify-work`:** `just ci`, both e2e backends, conformance workflow green
- **Max feedback latency:** 120 seconds for task-level checks
