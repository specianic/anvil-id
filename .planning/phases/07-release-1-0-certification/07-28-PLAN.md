AnvilID facts that shape the harness (read from the code, 2026-11-27):
- `SamlConfig.sso_url` and `metadata_url` must be https (crates/anvil-core/src/model/saml.rs). Every IdP must
  therefore serve https. Only the browser talks to the SSO URL; AnvilID fetches only the metadata URL.
- Outbound client (crates/anvil-web/src/adapters/outbound.rs, crates/anvilid/src/startup.rs): with an http
  localhost public URL (dev mode), loopback is allow-listed. `outbound_ca_file` (env `ANVILID_OUTBOUND_CA_FILE`, a
  PEM bundle) adds trusted roots. tests/e2e/run.sh starts anvilid with `env "${env_args[@]}"`, which inherits the
  caller's environment, so exporting ANVILID_OUTBOUND_CA_FILE before calling it is enough. Use a per-run CA plus a
  leaf certificate with SAN `IP:127.0.0.1` and `DNS:localhost`, as tests/conformance/run.sh does (webpki rejects a
  self-signed leaf used as a root).
- Org domains: `normalize_domain` (crates/anvil-core/src/policy/home_realm.rs) REFUSES `*.test`, `*.example`,
  `*.local`, `*.localhost`, `*.invalid` and `*.internal`. Verified, routed domains therefore use RFC 2606
  `*.interop.example.com` names (verified only through the suite's mock DNS, never looked up on the internet).
  Addresses that must NOT be on a verified domain use `example.test`.
- Signature profile (crates/anvil-web/src/adapters/saml_xml.rs): `KeyInfo` with `X509Data` or `KeyName` is accepted
  as a hint. RetrievalMethod and the like are refused. The assertion must be signed; a Response signature is
  optional but must verify. Only exc-c14n and enveloped+exc-c14n transforms. SHA-256+ only. No encrypted elements.
  NameID `persistent`, `emailAddress` or `unspecified` (transient is refused).
- Attribute mapping: `email`, `given_name`, `family_name`, `name`, each from an attribute `Name` or `FriendlyName`.
- SP values for tenant `interop`, connection `{slug}`, with E2E_PORT (default 18090): entity ID
  `http://localhost:$E2E_PORT/t/interop/saml/{slug}`, ACS `http://localhost:$E2E_PORT/t/interop/ui/login/saml/{slug}/acs`,
  SP metadata `http://localhost:$E2E_PORT/t/interop/saml/{slug}/metadata`. These values are deterministic, so IdPs are

- Audit: `GET /api/admin/v1/tenants/{slug}/audit-events?action=saml_login_failed` (AuditQueryParams: from, to, actor,
