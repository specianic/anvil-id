  `fn new_request_uri(random32: [u8;32]) -> (String, RequestUriHash)`, `fn parse_request_uri(&str) ->
  Option<RequestUriHash>` (prefix + exactly 43 b64url chars), plus the list of parameters ignored on the front channel.

  stored, already validated params replace the query parameters. Keep the existing refusal for every other value.

  trusted redirect URI. Use the existing error-page path in protocol/authorize.rs.
