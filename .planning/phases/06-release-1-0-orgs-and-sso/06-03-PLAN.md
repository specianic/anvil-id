- Precedent: `tests/e2e/lib/mock-idp.ts` (04-03): node:http + node:crypto only, binds 127.0.0.1, generates keys at start-up,
  self-tested by `specs/mock-idp.spec.ts`; run with `tests/e2e/run.sh sqlite specs/mock-idp.spec.ts` or plain
  `npx playwright test specs/mock-idp.spec.ts` (the self-test needs no anvilid).
- `xml-crypto` 6.4.0 (MIT) is the only new devDependency; pin it exactly like the other devDependencies; `npm install` updates
  package-lock.json. xml-crypto signs the `saml:Assertion` with an enveloped exc-c14n RSA-SHA256 signature whose single Reference is
  `#{assertion ID}`, placed as a direct child of the assertion after `saml:Issuer` (the profile 06-09 pins).
- The SP side (AnvilID, 06-18): entity ID `{issuer}/saml/{slug}`, ACS `{issuer}/ui/login/saml/{slug}/acs`, AuthnRequest via
  HTTP-Redirect (`SAMLRequest` = base64(DEFLATE(xml)), `RelayState` <= 80 bytes). The mock inflates `SAMLRequest` with node:zlib
  `inflateRawSync`, reads `ID`, `AssertionConsumerServiceURL`, `Issuer`, and answers with `InResponseTo` = that ID, `Destination` =
  ACS, `Recipient` = ACS, `Audience` = SP entity ID, `NotBefore`/`NotOnOrAfter` = now -/+ 5 min, NameID = the configured user's id,
  attributes email/given_name/family_name.
- Self-signed certificate: generate with node:crypto (`generateKeyPairSync('rsa', 2048)` + `X509Certificate` cannot create certs);
  use a minimal DER builder in the helper or `crypto.createSign` over a hand-built TBSCertificate (keep it small and commented), or
  the `selfsigned` approach implemented locally. Do not add another npm dependency for it.
- Mock DNS: a UDP responder decoding the question section, answering TXT (type 16) for exact names (case-insensitive, trailing dot
  tolerant) with one RR per configured value, each split into 255-byte character-strings; NXDOMAIN otherwise; TC flag never set
  (values stay small). AnvilID reaches it through the operator key `domain_verification_resolvers` (06-04) set to
  `127.0.0.1:<port>` by run.sh in 06-23, which also starts the single suite-wide instance via `mock-dns-cli.ts`
  (`--port`, `--control-port`; prints `READY` and exits on SIGTERM; same shape as lib/mock-idp-cli.ts).

Add `xml-crypto` 6.4.0 to devDependencies (`npm install --save-dev --save-exact xml-crypto@6.4.0` in tests/e2e). Write
`startMockSamlIdp({ entityId?, port? })` returning `{ url, ssoUrl, entityId, certPem, metadataXml, setUser(user), setVariant(v),

decode the response, verify the signature with xml-crypto's `SignedXml.checkSignature` against `certPem`, check InResponseTo /
Audience / Destination, and check the `unsigned` variant has no Signature. Type-check with `npx tsc --noEmit -p .`.
